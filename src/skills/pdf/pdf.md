# PDF Publication Skill

## Overview
Generates publication-grade, professionally formatted multi-page PDF documents.

## Themes (5 Visual Styles)
1. **editorial_clean** (Default): Minimalist, academic, monochrome black and white editorial layout.
2. **retro_pixel**: 8-bit arcade and cyber retro terminal style with dotted accents.
3. **pastel_chic**: Soft lavender, chic pastel cards, and rounded pill badges.
4. **playful_pop**: Memphis pop style with vibrant contrast and colorful pill headers.
5. **aurora_neon**: Modern dark mode tech with neon gradients and glow accents.

## Structure Standards
- **Page Format:** A4 with 45pt margins.
- **Section Pacing:** Each major section delivers in-depth domain knowledge with structured subsections, key insight cards, KPI metrics, and comparison tables.
- **Strict Content Integrity:** Never regurgitate prompt instructions or page count meta-text in titles or headings.
